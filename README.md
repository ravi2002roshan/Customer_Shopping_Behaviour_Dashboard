## 🗃️ SQL Highlights

### Subquery — Discount Users Above Average Spend
```sql
SELECT customer_id, purchase_amount
FROM my_table
WHERE discount_applied = 'Yes' 
  AND purchase_amount > (SELECT AVG(purchase_amount) FROM my_table);
```

### CASE Logic — Discount Rate Per Product
```sql
SELECT 
    item_purchased,
    ROUND(100 * SUM(CASE WHEN discount_applied = 'Yes' THEN 1 ELSE 0 END) / COUNT(*), 2) AS discount_rate
FROM my_table
GROUP BY item_purchased
ORDER BY discount_rate DESC
LIMIT 5;
```

### Multi-Metric Aggregation — Subscriber Analysis
```sql
SELECT 
    subscription_status,
    COUNT(customer_id) AS total_customers,
    ROUND(AVG(purchase_amount), 2) AS avg_spend,
    ROUND(SUM(purchase_amount), 2) AS total_revenue
FROM my_table
GROUP BY subscription_status
ORDER BY total_revenue DESC, avg_spend DESC;
```

## ▶️ How to Run

### MySQL Queries
1. Import your dataset into MySQL Workbench or any MySQL client
2. Create a table named `my_table` matching the dataset schema
3. Run queries from `customer_shopping_behaviour_analysis.sql`

### Python Notebook
```bash
# Clone the repository
git clone https://github.com/your-username/customer-shopping-behaviour-analysis.git
cd customer-shopping-behaviour-analysis

# Install dependencies
pip install pandas matplotlib seaborn jupyter

# Launch notebook
jupyter notebook customer_shopping_behaviour.ipynb
```

### Power BI Dashboard
1. Open `customer_behaviour_dashboard.pbix` in **Power BI Desktop**
2. Update the data source path if prompted
3. Refresh the data and explore the visuals

## 📂 Dataset

The dataset contains customer-level shopping transaction records with the following key fields:

| Column | Description |
|--------|-------------|
| `customer_id` | Unique customer identifier |
| `gender` | Customer gender |
| `item_purchased` | Product/item name |
| `purchase_amount` | Transaction value (USD) |
| `review_rating` | Customer product rating (1–5) |
| `shipping_type` | Delivery method (Standard, Express, etc.) |
| `discount_applied` | Whether a discount was used (Yes/No) |
| `subscription_status` | Whether the customer is subscribed (Yes/No) |
